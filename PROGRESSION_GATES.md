# Trollcraft III — Progression Gates

Which items to disable or change to make progression harder. Read from the recipes in the pack's 38 progression-mod jars (default recipes).
The searchable version of this list is published as a page; this file has the same data.

**Gate:** Solid = only its own mod makes it. Leaky = another mod, a shared `forge:` tag or Mystical Agriculture essence can make it, so close those routes too. Loot = not craftable.

## Watch these before you change anything

- **Mystical Agriculture is the biggest bypass.** Its resource seeds turn essence into other mods' gate items (all four AE2 Inscriber presses, Grains of Infinity, Terrasteel, Refined Obsidian, Draconium, steel, yellorium, cobalt and more; 312 essence recipes). Remove the essence recipe (`mysticalagriculture:essence/<mod>/<item>`), the seed recipe, or switch the seed off in its config.
- **Shared metals** (steel, brass, bronze, electrum, silver, lead, uranium) share `forge:` tags across mods. Gate the part made from the metal instead.
- **Yellorium** is also `forge:ingots/uranium`.
- **Boss mods** (Alex's Caves, Mowzie's Mobs, Alex's Mobs) have no recipe ladders; their boss drops make good extra ingredients in other mods' gate recipes.

## How to change a recipe

```js
// kubejs/server_scripts/progression_gates.js  (then run /reload)
ServerEvents.recipes(event => {
  // Make Mekanism's Steel Casing need a Create Precision Mechanism (in place of the osmium)
  event.remove({ output: 'mekanism:steel_casing' })
  event.shaped('mekanism:steel_casing', ['SGS', 'GPG', 'SGS'], {
    S: '#forge:ingots/steel', G: '#forge:glass/silica', P: 'create:precision_mechanism'
  })

  // Swap one ingredient in an existing recipe (Thermal Machine Frame: iron -> IE steel plate)
  event.replaceInput({ output: 'thermal:machine_frame' }, '#forge:ingots/iron', 'immersiveengineering:plate_steel')

  // Close a Mystical Agriculture bypass: one essence recipe...
  event.remove({ id: 'mysticalagriculture:essence/appliedenergistics2/silicon_press' })
  // ...or every essence recipe for one mod
  event.remove({ id: /^mysticalagriculture:essence\/appliedenergistics2\// })

  // Disable an item completely: removes every recipe that makes it, from any mod
  event.remove({ output: 'draconicevolution:chaotic_core' })
})
```

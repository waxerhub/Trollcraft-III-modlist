# Trollcraft III (Friendly Fire Trimmed) — Progression Mods

Source: `Trollcraft III Friendly Fire Trimmed.zip` (198 jars, Minecraft 1.20.1 Forge).
Mod names and versions are read from each jar's `mods.toml`.

The zip only contains the `mods/` folder (no `config/`, `kubejs/` or quest files),
so this list assumes default recipes. If the pack changes recipes, the guides
will need to be checked in-game with JEI.

---

| **Iron Chests / Ender Storage / Tool Belt / Waystones** | — | Small gated upgrades (chest tiers, ender pouches, belt upgrades, warp items) that fit as notes inside other guides |

### Vanilla milestones the guides depend on

- **Nether**: needed for Tinkers (cobalt), Mekanism (refined obsidian), ProjectE, EvilCraft and others.
  **Nether Ores Plus+** adds extra ore variants there.
- **The End / Ender Dragon**: required for Draconic Evolution (dragon heart) and many late recipes.
  **YUNG's Better End Island** and **dragonfight** change the fight, so warn players.
- **Ore processing**: **AlmostUnified** merges duplicate ores and ingots across Thermal, Mekanism,
  IE and Create. **Large Ore Deposits** adds rare, huge ore veins worth scouting early.

## Suggested overall order (for sequencing the guides)

1. **Early game:** Tinkers' Construct (smeltery and tools), Create (andesite age), Mystical Agriculture (Inferium seeds), Botania (Pure Daisy and mana)
2. **Early-mid game:** Immersive Engineering (steel), Thermal (dynamos and machines), Ender IO (alloy smelter and SAG mill), Mekanism (basic tier and 2x–3x ore processing)
3. **Mid game:** AE2 storage → autocrafting, Extreme Reactors, Create brass/trains, EvilCraft, ProjectE (EMC), Modular Powersuits, Alex's Caves biomes
4. **Late game:** Mekanism 5x processing and fusion, RFTools dimensions, Botania Gaia Guardian, ProjectE red matter, Ender Dragon
5. **Endgame:** Draconic Evolution (Wyvern → Awakened → Chaotic), Mekanism SPS/antimatter, MekaSuit
